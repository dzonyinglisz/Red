# Pięć Koszmarnych Nocy w Zespole Szkół Technicznych - Pochodzenie
"Five Nights at ZST - Origins" is a 2D FNaF style horror game written in C++ and Raylib as a school project submission. The neccessary documentation can be found in DOCS.md file located next to this one.

### 🍀 FEATURES:
This game isn't too advanced but still pretty awesome and impresive:
- Simple and beautiful 2D hand-drawn graphics
- Fun gameplay with a twist on the main premise
- Lot's of inside jokes
